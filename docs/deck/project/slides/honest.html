Trust and honest limits

Demo data is always labelled. Unknown stays Unknown.

How we keep it honest

  • Fictional competitors carry “(demo)” and a ribbon
  • Real companies: only values their saved page states
  • Scraped HTML never runs in the app (sandboxed iframe)
  • Reports drop any claim without evidence
  • Every decision is logged with its reason

Not built tonight

  • LLM extraction for JavaScript-heavy real pages
  • Internet Archive backfill of older prices
  • Scheduled monitoring (runs are on demand)
  • Marketplace and review sources
The decision log has over 70 decisions and 18 learnings, each with the options, the reason and the evidence, so any “why” from the judges has a written answer.
